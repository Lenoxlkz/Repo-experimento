# 🌌 Cosmos: Un Viaje Narrativo por el Universo

Una Landing Page educativa diseñada para explorar los misterios del cosmos a través de una experiencia visual inmersiva y narrativa.

## 🚀 Sobre el Proyecto

Este sitio web nace con la misión de traducir conceptos complejos de astrofísica y matemáticas en una historia accesible y fascinante. No es solo una página informativa; es un recorrido guiado desde las leyes fundamentales hasta los abismos más profundos del espacio-tiempo.

### Secciones Principales
- **Inicio:** Una introducción atmosférica al viaje cósmico.
- **Leyes Universales:** Explicación narrativa de la Gravedad, Relatividad y Mecánica Cuántica.
- **Galaxias:** Clasificación y naturaleza de las islas cósmicas.
- **Agujeros Negros:** Exploración del horizonte de sucesos, singularidades y radiación de Hawking.

## 🛠️ Tecnologías

Construido con cero dependencias externas para máxima ligereza y rendimiento:
- **HTML5 Semántico:** Estructura clara y accesible.
- **CSS3 Moderno:** Variables, Grid, Flexbox y animaciones puras.
- **Vanilla JavaScript:** Generación procedural de estrellas y efectos de scroll sin librerías.

## 🖥️ Cómo Visualizarlo

1. Clona este repositorio.
2. Abre el archivo `index.html` en tu navegador favorito.
3. ¡Disfruta del viaje!

## 📚 Enfoque Educativo

El contenido ha sido curado para equilibrar rigor científico con claridad narrativa. Las fórmulas matemáticas se presentan no como barreras, sino como la poesía subyacente de la realidad física.
